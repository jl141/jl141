T&T

Some tools/tricks I enjoy and use often.

Jumpcut

Clipboard text history
  • Simple MacOS clipboard history.
  • I only need clipboard history for text. Maybe I'll hack this or switch to something else if I end up needing image support.
  • Link to site: Jumpcut

Rectangle

Window sizing/placement
  • Offers straightforward keybinds to resize and move windows around. Can also easily move windows across multiple displays.
  • Cleaner than manual resizing and faster than MacOS's built-in resize menu.
  • Link to site: Rectangle

Linearmouse

Mouse & trackpad tool
  • I enjoy pointer acceleration when I'm using my Macbook's trackpad. I do not enjoy it when I'm trying to play Osu or Minecraft.
  • Linearmouse offers control over pointer speed/acceleration and scroll direction across different tracking devices.
  • Link to site: Linearmouse

Ice

Menu bar management
  • Hides messy menu bar until you hover over it.
  • Control item spacing for space efficiency. Mine are quite compact :)
  • Search through menu bar items (not updated for newer MacOS versions yet).
  • Link to site: Ice Menu Bar

MacOS Thermal Checkup

Terminal commands
  • I'm not aware of an easier way to check thermal load on MacOS. Need root permissions for powermetrics; give password to sudo.
  • Flag -s specifies the type of sampler, and -n specifies the number of samples.
    • 
                  % sudo powermetrics -s thermal -n 1
  • The result varies between: nominal, moderate, heavy, sleeping, & trapping. Should probably let your Mac cool down if at heavy or beyond.

MarkEdit

Markdown text editor
  • If I'm editing a lone markdown file (not part of some project repo) then I'll use MarkEdit instead of VSCode.
  • Clean UI, with several preview options if you install the preview extension.

Tangerine

Offline file converter
  • Quite convenient. Check it out here: Tangerine for Mac

Quick Word Counter

Terminal commands
  • Using wc in your shell is quicker than looking up a tool online, and uses heredoc to avoid having to escape apostrophes and quotations.
  • Start with this. The -w flag tells the wc tool to only count words. The double "less-than" feeds the impromptu document into wc.
    • 
                  % wc -w << 'EOF'
  • Enter, then paste your text.
    • 
                  heredoc> "THERE IT IS THAT'S THE WIN" - Marc Robert Lamont
  • To end the file, type EOF on a new line. The word count will show up in the next line.
    • 
                  heredoc> the rain went away but the puddles cling around
                  heredoc> EOF
                        19
